SPEC-125 clipboard captures — e2e/fixtures/spec125-clipboard/

Each file under the four capture names — excel.html, sheets.html,
libreoffice.html, numbers.html — is a real capture of its producer's own
clipboard HTML: Numbers and LibreOffice Calc run on the Mac, Google Sheets
and Excel for the web (or Excel desktop) in a browser on the Mac. No
generated, hand-written or edited file is ever committed under these names.

The range: A1:I1 of a fresh sheet in the producer's en-US locale, selected
and copied with the producer's own Copy.

  A1     the text Widget                                  General
  B1     1234567                                          thousands separator, no decimals (#,##0 — shows 1,234,567)
  C1     1234.5                                           the producer's US-dollar currency format (shows $1,234.50)
  D1     0.25                                             percentage, no decimals (shows 25%)
  E1     the date 2026-03-15                              the producer's short date format
  F1     the boolean TRUE (a checkbox in Numbers)         —
  G1     the formula =B1+C1 (shows 1235801.5)             General
  H1:I1  merged, holding the text Merged                  General

To capture: copy the range in the producer, then on the Mac run

  scripts/capture-clipboard-html.sh <name>      (excel, sheets, libreoffice or numbers)

which writes the clipboard's HTML flavour, byte for byte, to <name>.html
and prints its byte count. Then add the file's entry below.

One entry per capture file:

  <name>.html — producer: <Excel desktop | Excel for the web | Google Sheets | LibreOffice Calc | Numbers>
                version:  <the producer's version, or "web" and the capture date>
                macOS:    <version>    browser: <name and version, for a web producer>
                captured: <YYYY-MM-DD>
                deviations: <each cell the producer could not express as listed, or "none">

clipboard.spec.ts checks each capture against the table above, changed only
where its entry records a deviation; while a file is absent its tests (and
the e2e's external-paste steps for excel.html) skip with
"fixture not yet captured: <name>.html".
